# Weekly Retro

## Goal
1週間の Threads x note 運用を振り返り、来週の改善計画を作る。

## Inputs
- `CLAUDE.md`
- 今週の research / drafts / audits / analysis / retros
- review queue logs
- incident logs
- note draft throughput

## Steps
1. 今週の活動量を整理する
2. 勝ちテーマ / 負けテーマを分類する
3. hook / CTA / note導線 の成績を比較する
4. system bottleneck を特定する
5. 来週の実験案を3〜5本作る
6. やめること・続けること・強化することを決める
7. 保存先
   - `docs/retros/weekly-YYYY-WW.md`
   - `docs/progress.md` に要約追記

## Deliverables
- weekly retro report
- next week experiments
- system/process fixes
- content strategy changes

## Prohibited
- 単なる感想で終わらない
- 数字や evidence を無視しない
- 毎週同じ提案を繰り返さない

## Human Review Conditions
- 戦略転換が大きい場合
- 新しい自動返信ポリシー案
- 新しい note 公開フロー変更
