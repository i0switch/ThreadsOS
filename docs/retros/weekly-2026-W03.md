# Weekly Retro

🔧 委譲判定: 自分  
理由: 与えられたデータをもとにした振り返りレポート作成であり、設計判断と要約が中心のため

## 1. 概要
今週は**64投稿で合計3,220インプレッション、いいね5、返信0**でした。  
1投稿あたりの平均は**約50インプレッション**、反応率は**かなり低水準**で、特に**返信がゼロ**だった点から、共感や会話を生む設計が不足していたと見られます。

一方で、曜日・時間・テーマ・フック・CTAごとに差は出ており、全体が弱い中でも**勝ち筋の仮説は取れている週**でした。来週は投稿数を維持するより、**勝ち条件へ寄せる運用**に切り替えるのが有効です。

## 2. 勝ちパターン
- **投稿時間:** 14時が最良、20時が最弱  
- **曜日:** 金曜が最良、木曜が最弱  
- **テーマ:** 「**男の本気を見抜く完全マニュアル**」が最良  
- **フック:** **benefit型**が最良  
- **CTA:** **save型**が最良  

全体として、**実用性が高く、保存したくなる内容**が相対的に強く、逆にストーリー寄り・拡散依存の設計は刺さりにくい傾向が出ています。

## 3. 改善点
- **投稿数に対して反応が薄い**ため、量よりも配信精度の改善が必要
- **返信0**なので、意見を言いたくなる問いかけや対立軸が不足
- **木曜・20時・story・share**は優先度を下げるべき
- テーマによって差があるため、**曖昧な関係の見極め方**の見せ方は再設計が必要

## 4. 来週の実験案
1. **14時×金曜×benefit×save**の勝ちパターンを集中投入する  
2. 「男の本気を見抜く完全マニュアル」を**切り口だけ変えて3〜5本再展開**する  
3. 弱かった「曖昧な関係の見極め方」は、**抽象論からチェックリスト型**へ変えて再テストする  
4. storyフックは減らし、**冒頭で得られる利益を明言する型**を増やす  
5. reply獲得用に、週1〜2本だけ**質問終わり・二択終わり**の投稿を入れる  

## 5. 投稿時間・テーマ・フック・CTAの改善方針
- **投稿時間:** 14時を主軸にし、20時は停止または大幅削減  
- **テーマ:** 「男の本気を見抜く完全マニュアル」系の**判断基準・見抜き方・チェック項目**を横展開  
- **フック:** story型より、**読むと何が得かを最初に示すbenefit型**を標準化  
- **CTA:** shareではなく、**「あとで見返せるので保存しておいて」系のsave訴求**を基本にする  

来週は、**勝ち要素へ寄せて反応率を上げる週**にするのが最優先です。量産よりも、**14時・金曜・実用テーマ・benefit・save**の再現性を取りにいくべきです。
