# ThreadsOS 修正案: 完全自律運用への改修

作成日: 2026-03-29

## 概要

ThreadsOS を「人間が毎回指示する」運用から「1時間おきハートビートで全自動運用」に改修する。
人間がやるのは初回ジャンル選定と、公開後の note サムネ設定のみ。

---

## Part A: バグ修正 (監査指摘 F1-F4)

### A-1. [P1] post-publish-followup が成功扱いのまま何もしていない

**対象**: `src/services/orchestration/index.ts:98-106`

**現状**: 本番実行でも固定文字列を返して `completed` 扱い。運用者がフォローアップ完了と誤認する。

**修正内容**:
```typescript
async runPostPublishFollowup(api: ThreadsApiClient, llm: LlmClient, dryRun = false): Promise<string> {
  logger.info({ dryRun }, "Starting post publish followup");
  if (dryRun) return "[DRY-RUN] Would fetch and classify replies.";

  // 直近24時間の投稿結果を取得
  const recentResults = db.select().from(threadPostResults)
    .where(gte(threadPostResults.createdAt, dayAgo))
    .all();

  if (recentResults.length === 0) {
    return "No recent posts to follow up on.";
  }

  let repliesProcessed = 0;
  for (const result of recentResults) {
    // エンゲージメント再取得
    await this.engagementService.fetchAndStoreResults(result.draftId, result.threadsPostId, api);
    // 返信取得→分類
    await this.engagementService.fetchAndClassifyReplies(result.id, api, llm);
    // パフォーマンス分析
    await this.engagementService.analyzePostPerformance(result.id, llm);
    repliesProcessed++;
  }

  return `Processed ${repliesProcessed} posts, fetched replies and analyzed performance.`;
}
```

## Part B: 完全自律運用への改修

### B-1. 新しい駆動モデル: ハートビート方式

```
1時間おきハートビート (heartbeat.ts)
  │
  ├─ Scheduler: 「今何すべき？」を判断
  │    ├─ 時間帯・曜日
  │    ├─ 直近投稿からの経過時間
  │    ├─ 未処理の返信数
  │    ├─ 未公開の note ドラフト数
  │    ├─ 分析データの鮮度
  │    ├─ human_inputs の未処理件数
  │    └─ 最適投稿スケジュール（学習結果）
  │
  ├─ 決定したアクションを順次実行
  │
  └─ 2時間おきに進捗通知
```

#### `src/jobs/heartbeat.ts` — 全処理の起点

```typescript
import { runJob } from "./runner.js";
import { SchedulerServiceImpl } from "../services/scheduler/index.js";
import { OrchestrationServiceImpl } from "../services/orchestration/index.js";
import { AutoPublisherServiceImpl } from "../services/auto-publisher/index.js";
import { ScheduleOptimizerServiceImpl } from "../services/schedule-optimizer/index.js";
import { NotificationServiceImpl } from "../services/notification/index.js";
import { ClaudeLlmClient, DryRunLlmClient } from "../adapters/llm/index.js";
import { ThreadsGraphApiClient, DryRunThreadsApiClient } from "../adapters/threads-api/index.js";
import { FileSystemStorageClient } from "../adapters/storage/index.js";

const dryRun = process.argv.includes("--dry-run");

const llm = dryRun ? new DryRunLlmClient() : new ClaudeLlmClient();
const threadsApi = dryRun ? new DryRunThreadsApiClient() : new ThreadsGraphApiClient();
const storage = new FileSystemStorageClient();

const scheduler = new SchedulerServiceImpl();
const orchestration = new OrchestrationServiceImpl();
const autoPublisher = new AutoPublisherServiceImpl();
const optimizer = new ScheduleOptimizerServiceImpl();
const notification = new NotificationServiceImpl();

await runJob({ name: "heartbeat", dryRun }, async ({ dryRun, logger }) => {
  const actions = await scheduler.decideActions();
  logger.info({ actionCount: actions.length }, "Heartbeat: actions decided");

  const results: string[] = [];

  for (const action of actions) {
    logger.info({ action: action.type, reason: action.reason }, "Executing action");

    switch (action.type) {
      case "research_threads":
        results.push(await orchestration.runDailyTopicResearch(llm, storage, dryRun));
        break;

      case "research_note":
        // note 競合リサーチ（スクレイピング + 非公式API）
        results.push(await orchestration.runNoteResearch(llm, storage, dryRun));
        break;

      case "generate_and_post":
        // 生成 → 監査 → pass なら自動投稿
        results.push(await orchestration.runDailyThreadsPlan(llm, storage, dryRun));
        const published = await autoPublisher.publishApprovedThreadDrafts(threadsApi);
        results.push(`Auto-published ${published.length} threads posts`);
        break;

      case "fetch_engagement":
        results.push(await orchestration.runPostPublishFollowup(threadsApi, llm, dryRun));
        break;

      case "reply_safe":
        const repliesSent = await autoPublisher.sendSafeReplies(threadsApi);
        results.push(`Sent ${repliesSent} safe replies`);
        break;

      case "generate_note":
        results.push(await orchestration.runNightlyNotePipeline(llm, storage, dryRun));
        const noteResults = await autoPublisher.publishApprovedNoteDrafts();
        results.push(`Auto-published ${noteResults.length} notes`);
        // 公開した note ごとに「サムネ設定してね」通知
        for (const nr of noteResults) {
          await notification.sendNotification({
            type: "action_needed",
            message: `note公開しました。サムネを設定してください: ${nr.url}`,
          });
        }
        break;

      case "optimize_schedule":
        await optimizer.analyzeAndUpdate();
        results.push("Schedule optimized");
        break;

      case "notify":
        const report = await notification.generateProgressReport();
        await notification.sendNotification({ type: "progress", report });
        results.push("Progress notification sent");
        break;

      case "process_human_inputs":
        // 人間からの追加リサーチ・フィードバックを取り込む
        results.push(await orchestration.processHumanInputs(llm, storage));
        break;
    }
  }

  return results.join("\n");
});
```

#### `src/services/scheduler/index.ts` — ハートビートの頭脳

```typescript
import { db } from "../../db/index.js";
import { scheduledJobRuns, postingSchedules, threadPostResults,
         replyDecisions, humanInputs, notifications } from "../../db/schema.js";
import { eq, and, gte, desc } from "drizzle-orm";
import { logger } from "../../app/logger.js";

export type ActionType =
  | "research_threads"
  | "research_note"
  | "generate_and_post"
  | "fetch_engagement"
  | "reply_safe"
  | "generate_note"
  | "optimize_schedule"
  | "notify"
  | "process_human_inputs";

export interface ScheduledAction {
  type: ActionType;
  priority: number;    // 1が最高
  reason: string;
}

export interface SchedulerService {
  decideActions(): Promise<ScheduledAction[]>;
}

export class SchedulerServiceImpl implements SchedulerService {
  async decideActions(): Promise<ScheduledAction[]> {
    const actions: ScheduledAction[] = [];
    const now = new Date();
    const hour = now.getHours();
    const nowIso = now.toISOString();

    // --- 未処理 human_inputs があれば最優先で取り込む ---
    const pendingInputs = db.select().from(humanInputs)
      .where(eq(humanInputs.processed, 0)).all();
    if (pendingInputs.length > 0) {
      actions.push({
        type: "process_human_inputs",
        priority: 1,
        reason: `${pendingInputs.length}件の未処理human_inputs`,
      });
    }

    // --- 2時間おき通知 (偶数時) ---
    if (hour % 2 === 0) {
      const lastNotify = db.select().from(notifications)
        .orderBy(desc(notifications.sentAt))
        .limit(1).get();
      const lastNotifyAge = lastNotify
        ? (now.getTime() - new Date(lastNotify.sentAt).getTime()) / 3600000
        : 999;
      if (lastNotifyAge >= 1.5) {
        actions.push({ type: "notify", priority: 2, reason: "2時間おき通知" });
      }
    }

    // --- 未送信の safe 返信があれば送る ---
    const pendingReplies = db.select().from(replyDecisions)
      .where(eq(replyDecisions.decision, "safe_auto_reply"))
      .all();
    // TODO: sent フラグで絞り込む（DB拡張後）
    if (pendingReplies.length > 0) {
      actions.push({
        type: "reply_safe",
        priority: 3,
        reason: `${pendingReplies.length}件の safe 返信待ち`,
      });
    }

    // --- 投稿スケジュールに基づく投稿 ---
    const dueSchedules = db.select().from(postingSchedules)
      .where(and(
        eq(postingSchedules.status, "pending"),
        // scheduledAt <= now
      )).all()
      .filter(s => new Date(s.scheduledAt) <= now);

    if (dueSchedules.some(s => s.actionType === "threads_post")) {
      actions.push({
        type: "generate_and_post",
        priority: 4,
        reason: "投稿スケジュールの時刻到達",
      });
    }
    if (dueSchedules.some(s => s.actionType === "note_publish")) {
      actions.push({
        type: "generate_note",
        priority: 5,
        reason: "note公開スケジュールの時刻到達",
      });
    }

    // --- エンゲージメント取得 (直近投稿から1時間以上経過) ---
    const recentPosts = db.select().from(threadPostResults)
      .orderBy(desc(threadPostResults.createdAt))
      .limit(5).all();
    const needsEngagement = recentPosts.some(p => {
      const age = (now.getTime() - new Date(p.createdAt).getTime()) / 3600000;
      return age >= 1 && age <= 48; // 1〜48時間の投稿は追跡対象
    });
    if (needsEngagement) {
      actions.push({
        type: "fetch_engagement",
        priority: 6,
        reason: "直近投稿のエンゲージメント追跡",
      });
    }

    // --- リサーチ (最終リサーチから24h経過) ---
    const lastResearchJob = db.select().from(scheduledJobRuns)
      .where(eq(scheduledJobRuns.jobName, "daily-topic-research"))
      .orderBy(desc(scheduledJobRuns.startedAt))
      .limit(1).get();
    const researchAge = lastResearchJob
      ? (now.getTime() - new Date(lastResearchJob.startedAt).getTime()) / 3600000
      : 999;
    if (researchAge >= 24) {
      actions.push({
        type: "research_threads",
        priority: 7,
        reason: `前回リサーチから${Math.floor(researchAge)}時間経過`,
      });
      actions.push({
        type: "research_note",
        priority: 8,
        reason: "Threadsリサーチと併せてnote競合調査",
      });
    }

    // --- スケジュール最適化 (1日1回, 深夜) ---
    if (hour === 0 || hour === 1) {
      actions.push({
        type: "optimize_schedule",
        priority: 9,
        reason: "日次スケジュール最適化",
      });
    }

    // priority でソート
    actions.sort((a, b) => a.priority - b.priority);

    logger.info({ actions: actions.map(a => a.type) }, "Scheduler decided actions");
    return actions;
  }
}
```

#### `src/services/auto-publisher/index.ts` — 自動投稿・公開

```typescript
import { eq, and } from "drizzle-orm";
import { db } from "../../db/index.js";
import { threadPostDrafts, threadPostResults, replyDecisions,
         threadReplies, noteDrafts } from "../../db/schema.js";
import { logger } from "../../app/logger.js";
import { assertNoteMode } from "../../adapters/note-research/index.js";
import type { ThreadsApiClient } from "../../adapters/threads-api/index.js";

export interface PublishResult {
  id: string;
  url: string;
  type: "threads" | "note";
}

export interface AutoPublisherService {
  publishApprovedThreadDrafts(api: ThreadsApiClient): Promise<PublishResult[]>;
  publishApprovedNoteDrafts(): Promise<PublishResult[]>;
  sendSafeReplies(api: ThreadsApiClient): Promise<number>;
}

export class AutoPublisherServiceImpl implements AutoPublisherService {

  // 1時間あたり投稿上限
  private readonly MAX_POSTS_PER_HOUR = 3;
  private readonly MAX_REPLIES_PER_HOUR = 10;

  async publishApprovedThreadDrafts(api: ThreadsApiClient): Promise<PublishResult[]> {
    // status=audited (監査pass済み) かつ未投稿のドラフトを取得
    const approved = db.select().from(threadPostDrafts)
      .where(eq(threadPostDrafts.status, "audited"))
      .limit(this.MAX_POSTS_PER_HOUR)
      .all();

    const results: PublishResult[] = [];

    for (const draft of approved) {
      try {
        const { id: postId, permalink } = await api.publishPost(draft.body);

        // status を published に更新
        db.update(threadPostDrafts).set({
          status: "published",
          updatedAt: new Date().toISOString(),
        }).where(eq(threadPostDrafts.id, draft.id)).run();

        // 投稿結果を記録
        const now = new Date().toISOString();
        db.insert(threadPostResults).values({
          id: randomUUID(),
          draftId: draft.id,
          threadsPostId: postId,
          impressions: 0,
          likes: 0,
          repliesCount: 0,
          shares: 0,
          publishedAt: now,
          createdAt: now,
        }).run();

        results.push({ id: postId, url: permalink, type: "threads" });
        logger.info({ draftId: draft.id, postId }, "Auto-published to Threads");
      } catch (error) {
        logger.error({ draftId: draft.id, error }, "Failed to auto-publish");
      }
    }

    return results;
  }

  async publishApprovedNoteDrafts(): Promise<PublishResult[]> {
    // NOTE_MODE チェック — draft_assist 以上でないと throw
    assertNoteMode(["draft_assist", "browser_assisted"]);

    // score >= 7 かつ status=audited のドラフト
    const approved = db.select().from(noteDrafts)
      .where(eq(noteDrafts.status, "audited"))
      .all()
      .filter(d => (d.publishReadinessScore ?? 0) >= 7);

    const results: PublishResult[] = [];

    for (const draft of approved) {
      try {
        // TODO: NoteApiClient.publishArticle() で公開
        // const { noteId, url } = await noteApi.publishArticle(draft.title, draft.body);

        // 公開後: status を approved に（公開済み扱い）
        db.update(noteDrafts).set({
          status: "approved",
          updatedAt: new Date().toISOString(),
        }).where(eq(noteDrafts.id, draft.id)).run();

        // サムネはつけない。公開後に人間が note 編集画面で設定する。
        // 通知は heartbeat.ts 側で送る。

        const url = `https://note.com/placeholder/${draft.id}`;
        results.push({ id: draft.id, url, type: "note" });
        logger.info({ draftId: draft.id }, "Auto-published to note (thumbnail pending)");
      } catch (error) {
        logger.error({ draftId: draft.id, error }, "Failed to auto-publish note");
      }
    }

    return results;
  }

  async sendSafeReplies(api: ThreadsApiClient): Promise<number> {
    // safe_auto_reply 判定で autoReplyBody がある返信を取得
    const pending = db.select({
      decision: replyDecisions,
      reply: threadReplies,
    }).from(replyDecisions)
      .innerJoin(threadReplies, eq(replyDecisions.replyId, threadReplies.id))
      .where(eq(replyDecisions.decision, "safe_auto_reply"))
      .limit(this.MAX_REPLIES_PER_HOUR)
      .all();

    let sent = 0;
    for (const { decision, reply } of pending) {
      if (!decision.autoReplyBody) continue;
      try {
        await api.replyToPost(reply.threadsReplyId, decision.autoReplyBody);
        // TODO: sent フラグを立てる（DB拡張後）
        sent++;
        logger.info({ replyId: reply.id }, "Auto-replied to thread");
      } catch (error) {
        logger.error({ replyId: reply.id, error }, "Failed to auto-reply");
      }
    }

    return sent;
  }
}
```

#### `src/services/schedule-optimizer/index.ts` — 投稿タイミング自動調節

```typescript
import { db } from "../../db/index.js";
import { threadPostResults, postingSchedules } from "../../db/schema.js";
import { desc } from "drizzle-orm";
import { randomUUID } from "node:crypto";
import { logger } from "../../app/logger.js";
import type { LlmClient } from "../../adapters/llm/index.js";

export interface TimeSlot {
  dayOfWeek: number;  // 0=日, 6=土
  hour: number;       // 0-23
  avgEngagementRate: number;
}

export interface ScheduleOptimizerService {
  analyzeOptimalTimes(): Promise<TimeSlot[]>;
  adjustFrequency(llm: LlmClient): Promise<string>;
  generateSchedule(days: number): Promise<void>;
  analyzeAndUpdate(): Promise<void>;
}

export class ScheduleOptimizerServiceImpl implements ScheduleOptimizerService {

  async analyzeOptimalTimes(): Promise<TimeSlot[]> {
    const results = db.select().from(threadPostResults).all();

    // 曜日×時間帯ごとにエンゲージメント率を集計
    const slots = new Map<string, { total: number; engagement: number; count: number }>();

    for (const r of results) {
      const d = new Date(r.publishedAt);
      const key = `${d.getDay()}-${d.getHours()}`;
      const existing = slots.get(key) ?? { total: 0, engagement: 0, count: 0 };
      existing.total += r.impressions;
      existing.engagement += r.likes + r.repliesCount + r.shares;
      existing.count++;
      slots.set(key, existing);
    }

    const timeSlots: TimeSlot[] = [];
    for (const [key, data] of slots) {
      const [dow, hour] = key.split("-").map(Number);
      timeSlots.push({
        dayOfWeek: dow,
        hour,
        avgEngagementRate: data.total > 0 ? data.engagement / data.total : 0,
      });
    }

    // エンゲージメント率で降順ソート
    timeSlots.sort((a, b) => b.avgEngagementRate - a.avgEngagementRate);

    return timeSlots;
  }

  async adjustFrequency(llm: LlmClient): Promise<string> {
    const results = db.select().from(threadPostResults)
      .orderBy(desc(threadPostResults.createdAt))
      .limit(30).all();

    const prompt = `以下の直近30投稿のデータから、最適な投稿頻度を分析してください。

${results.map(r => `${r.publishedAt}: imp=${r.impressions}, likes=${r.likes}, replies=${r.repliesCount}`).join("\n")}

以下の形式で回答:
{
  "recommendedPostsPerDay": 数値,
  "minIntervalHours": 数値,
  "reasoning": "理由"
}`;

    return llm.generate(prompt, { temperature: 0.3 });
  }

  async generateSchedule(days: number): Promise<void> {
    const optimalTimes = await this.analyzeOptimalTimes();
    const topSlots = optimalTimes.slice(0, 5); // 上位5スロット

    const now = new Date();

    for (let d = 0; d < days; d++) {
      const date = new Date(now);
      date.setDate(date.getDate() + d);

      for (const slot of topSlots) {
        if (date.getDay() !== slot.dayOfWeek) continue;

        const scheduledAt = new Date(date);
        scheduledAt.setHours(slot.hour, 0, 0, 0);

        if (scheduledAt <= now) continue;

        db.insert(postingSchedules).values({
          id: randomUUID(),
          scheduledAt: scheduledAt.toISOString(),
          actionType: "threads_post",
          status: "pending",
          createdAt: now.toISOString(),
        }).run();
      }
    }

    logger.info({ days }, "Posting schedule generated");
  }

  async analyzeAndUpdate(): Promise<void> {
    await this.analyzeOptimalTimes();
    await this.generateSchedule(7); // 向こう7日分
    logger.info("Schedule optimized and updated");
  }
}
```

```typescript
import { db } from "../../db/index.js";
import { threadPostResults, noteDrafts, humanReviewItems,
         postingSchedules, notifications } from "../../db/schema.js";
import { eq, gte, desc } from "drizzle-orm";
import { randomUUID } from "node:crypto";
import { logger } from "../../app/logger.js";
import type { StorageClient } from "../../adapters/storage/index.js";

export interface ProgressReport {
  timestamp: string;
  todayStats: {
    threadsPosted: number;
    totalImpressions: number;
    totalLikes: number;
    totalReplies: number;
    notesPublished: number;
    repliesSent: number;
    pendingReviews: number;
  };
  recentPosts: Array<{ body: string; impressions: number }>;
  upcomingSchedule: Array<{ scheduledAt: string; actionType: string }>;
  improvements: string[];
}

export interface NotificationPayload {
  type: "progress" | "action_needed" | "alert";
  message?: string;
  report?: ProgressReport;
}

export interface NotificationService {
  generateProgressReport(): Promise<ProgressReport>;
  sendNotification(payload: NotificationPayload): Promise<void>;
}

export class NotificationServiceImpl implements NotificationService {
  private storage: StorageClient;

  constructor(storage?: StorageClient) {
    // 遅延初期化可能
    this.storage = storage ?? (null as any);
  }

  async generateProgressReport(): Promise<ProgressReport> {
    const today = new Date().toISOString().split("T")[0];
    const todayStart = `${today}T00:00:00.000Z`;

    const todayResults = db.select().from(threadPostResults)
      .where(gte(threadPostResults.createdAt, todayStart)).all();

    const pendingReviews = db.select().from(humanReviewItems)
      .where(eq(humanReviewItems.status, "pending")).all();

    const upcoming = db.select().from(postingSchedules)
      .where(eq(postingSchedules.status, "pending"))
      .orderBy(postingSchedules.scheduledAt)
      .limit(5).all();

    return {
      timestamp: new Date().toISOString(),
      todayStats: {
        threadsPosted: todayResults.length,
        totalImpressions: todayResults.reduce((s, r) => s + r.impressions, 0),
        totalLikes: todayResults.reduce((s, r) => s + r.likes, 0),
        totalReplies: todayResults.reduce((s, r) => s + r.repliesCount, 0),
        notesPublished: 0, // TODO: note公開履歴から取得
        repliesSent: 0,    // TODO: 送信済み返信数
        pendingReviews: pendingReviews.length,
      },
      recentPosts: todayResults.slice(0, 5).map(r => ({
        body: "", // TODO: draft から取得
        impressions: r.impressions,
      })),
      upcomingSchedule: upcoming.map(s => ({
        scheduledAt: s.scheduledAt,
        actionType: s.actionType,
      })),
      improvements: [],
    };
  }

  async sendNotification(payload: NotificationPayload): Promise<void> {
    const now = new Date();
    const id = randomUUID();

    let content: string;
    if (payload.type === "progress" && payload.report) {
      const r = payload.report;
      content = [
        `## 進捗レポート ${r.timestamp}`,
        "",
        `- Threads投稿: ${r.todayStats.threadsPosted}本`,
        `- インプレッション: ${r.todayStats.totalImpressions}`,
        `- いいね: ${r.todayStats.totalLikes}`,
        `- 返信: ${r.todayStats.totalReplies}`,
        `- レビュー待ち: ${r.todayStats.pendingReviews}件`,
        "",
        "### 今後のスケジュール",
        ...r.upcomingSchedule.map(s => `- ${s.scheduledAt}: ${s.actionType}`),
      ].join("\n");
    } else {
      content = payload.message ?? "";
    }

    // DB に記録
    db.insert(notifications).values({
      id,
      type: payload.type,
      content,
      sentAt: now.toISOString(),
      channel: "file",
    }).run();

    // ファイルに保存
    const fileName = `docs/notifications/${now.toISOString().replace(/[:.]/g, "-")}.md`;
    if (this.storage) {
      await this.storage.saveFile(fileName, content);
    }

    logger.info({ type: payload.type, id }, "Notification sent");

    // TODO: 将来は Discord Webhook / LINE Notify に送信
  }
}
```
